# Mini Helpdesk System --- Frontend

Angular application for Helpdesk ticket management with JWT
authentication, RBAC, dashboards, and ticket workflow UI.

## Tech Stack

-   Node V20.15.0
-   Angular 17
-   TypeScript
-   Bootstrap 5
-   RxJS
-   Reactive Forms

## Features

-   JWT Auth + Refresh Flow
-   Role Guards
-   Ticket Dashboard
-   Comments & Activity Timeline
-   Server-side Pagination

## Setup

### Install

npm install

### Run

ng serve
